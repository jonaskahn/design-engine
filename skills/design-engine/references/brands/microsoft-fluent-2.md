# Microsoft Fluent 2
Source: https://fluent2.microsoft.design/ (design tokens, color, typography, components)
Verify at lock-in: which version applies — Fluent 2 is current, Fluent 3 is emerging.
Character: Professional and broadly appealing enterprise UI. Dense enough for Office-scale apps, approachable enough for consumer apps.
Poor fit for: boutique/artisan brands, editorial
Palette roles: colorNeutralBackground1 `#ffffff`, colorNeutralForeground1 `#242424`, colorBrandForeground1 `#0f6cbd`, colorBrandBackground `#0f6cbd`, colorDangerForeground1 `#b10e1c`, colorSuccessForeground1 `#107c10`, dark background `#292929` / `#1f1f1f`
Typography: Segoe UI (system/proprietary), Selawik as open substitute. Open fallback: Inter, Noto Sans. Type ramp in fixed steps (100–900).
Shape & space: 4px medium radius, 8px large; 4px spacing base; shadow depth 2–16
Motion: short, purposeful; Fluent motion durations 100–400ms with decelerate curves
Signature moves: neutral gray surfaces, brand-blue accent for interactive, rounded rectangular buttons, left rail nav (Teams/Outlook), elevated cards with subtle shadow
Licensing: Segoe UI font files are licensed for Windows only.
