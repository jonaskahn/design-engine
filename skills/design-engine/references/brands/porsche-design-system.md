Status: active. A public, code-backed design system (web components), so tokens are authoritative and current.
Character: Engineered luxury. Precise, restrained, technical — the system treats interfaces like precision instruments.
Best for: marketing, application-ui, ecommerce  ·  Poor fit for: playful consumer apps, community platforms

Shape & space: 4px radius; strict spacing scale (4/8/12/16/24/32/48); generous macro-spacing
Motion: controlled, mechanical easing; no whimsy
Signature moves: high-contrast dark/light alternation, thin uppercase action labels, engineered line work, full-bleed photography
Do not copy: Porsche crest/wordmark, Porsche Next font files outside license, "Porsche" in UI
Slop overlap: dark-only (deliberate for brand surfaces)
