# Porsche Design System
Source: https://designsystem.porsche.com/ (official web component design system)
Character: Engineered luxury. Precise, restrained, technical — the system treats interfaces like precision instruments.
Poor fit for: playful consumer apps, community platforms
Palette roles: light background `#FFF`, dark background `#0E0E12`, text `#000`/`#FFF`, neutral shades `#626669`, state colors: error `#FF0223`, success `#01BA1D`, warning `#FFF500`, focus `#0178B0`
Typography: Porsche Next (proprietary, licensed; available as web font for Porsche apps). Open fallback: Inter, Archivo. Precise technical sans, uppercase for key actions.
Shape & space: 4px radius; strict spacing scale (4/8/12/16/24/32/48); generous macro-spacing
Motion: controlled, mechanical easing; no whimsy
Signature moves: high-contrast dark/light alternation, thin uppercase action labels, engineered line work, full-bleed photography
Licensing: Porsche Next font files are licensed, not free.
Slop overlap: dark-only (deliberate for brand surfaces)
