# Linear
Source: https://linear.app/ (observable product/marketing design; no public token spec — record "observed from https://linear.app/")
Character: Precise, fast, and low-chrome. Keyboard-first product tooling with a quiet dark surface and restrained accent.
Poor fit for: public sector, retail ecommerce, playful brands
Palette roles: background near `#08090a`/`#101012`, panel `#141516`, border `#23252a`, text `#f7f8f8`, muted `#8a8f98`, accent violet `#5e6ad2`; light theme exists in marketing surfaces
Typography: Inter Variable (system choice here), tight tracking on headings. This is one of the places Inter is legitimate — not a default to copy elsewhere. Open fallback: Geist, Public Sans.
Shape & space: 4–8px radius; compact 4px spacing rhythm; flat surfaces with 1px borders
Motion: fast 120ms transitions; keyboard feedback is the motion language
Signature moves: 1px hairline borders, subtle violet accent on near-black, keyboard shortcut hints in tooltips, command palette, monospaced issue identifiers
Slop overlap: dark-only, Inter, glass blur in marketing (unlocked use is a tell)
