# Spotify (Encore Design System)
Source: https://developer.spotify.com/ (Encore design system / brand guidelines; observable consumer app)
Character: Energetic and audio-first. Bold color, high contrast, dense media browsing.
Poor fit for: enterprise dashboards, government
Palette roles: base black `#000000`/`#121212`, elevated `#242424`, text `#FFFFFF`, muted `#B3B3B3`, accent green `#1DB954`/`#1ED760`, bright accent set used in editorial cards
Typography: Circular / Spotify Mix (proprietary). Open fallback: Figtree, Public Sans. Bold display, high-x-height body.
Shape & space: 4–8px radius, rounded pill CTAs; 4px spacing base; dense media grids
Motion: energetic but contained; scroll-driven hero image changes, subtle hover lifts
Signature moves: green pill CTA on black, full-bleed editorial color cards, large album-art grid, circular icon buttons
Licensing: Circular and Spotify Mix font files are proprietary.
Slop overlap: dark-only, pill buttons, neon-green accent (deliberate here)
