# Shopify Polaris
Source: https://polaris.shopify.com/ (tokens, components, color, typography)
Character: Calm commerce. Friendly enough for merchants of any size, disciplined enough for dense admin screens.
Poor fit for: developer documentation, editorial
Palette roles: surface `#FFFFFF`, surface-sunken `#F6F6F7`, text `#1A1A1A`, text-secondary `#616161`, critical `#E51C00`, success `#108043`, warning `#FFC453`, brand ink `#1A1A1A` with accent green `#008060`; dark `#1A1A1A`
Typography: Shopify Sans / Shopify Sans Condensed (proprietary). Open fallback: Inter, Public Sans. Use sentence case; keep headings compact for dense UI.
Shape & space: 8px radius on cards, 12px on buttons/inputs; 4px spacing base with a 16px component rhythm
Motion: 150ms ease transitions; expand/collapse for bulk detail
Signature moves: rounded cards on a sunken surface, green primary action, status badges (critical/warning/success), the index table with bulk selection and filter chips
Licensing: Shopify Sans font files are proprietary.
Slop overlap: rounded-2xl cards (deliberate in this system), pill-shaped badges
