# Nothing (Nothing OS / Nothing Technology)
Source: https://nothing.tech/ , https://nothing.tech/pages/os (observable product/marketing)
Character: Stark monochrome with a single warm accent, dot-matrix texture, and industrial restraint. Deliberately unlike typical consumer tech.
Poor fit for: enterprise dashboards, content-heavy docs
Palette roles: black `#000000`, off-white `#F5F5F5`, pure white `#FFFFFF`, accent warm red/orange, transparent/dot-texture neutrals
Typography: dot-matrix display face and a plain grotesk body (verify licensing; proprietary face is likely). Open fallback: Space Mono or IBM Plex Mono for display cues, Inter for body — but note Space Mono is a slop-default font; only use if Nothing is explicitly locked.
Shape & space: low radius, industrial grid; textural dot patterns used sparingly and with purpose
Motion: minimal; mechanical/telegraphic reveals
Signature moves: dot-matrix type treatment, pure black/white, transparent hardware photo treatments, thin outlined iconography
Licensing: Glyph logo assets and trademarked typeface files.
Slop overlap: near-black + one accent (deliberate here; avoid unlocking elsewhere)
