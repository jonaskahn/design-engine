# IBM Carbon Design System
Source: https://carbondesignsystem.com/ (colors, type, components, GitHub carbon-design-system)  ·  Tokens verified: 2026-10 (model knowledge; re-verify at lock-in) against https://carbondesignsystem.com/guidelines/color/usage/
Status: active, widely maintained. Carbon 11 introduced inline themes, dense/dynamic tokens.
Character: Enterprise-serious and information-dense. Built for multi-product IBM software, so it favors clarity, systematic scale, and tabular data over decoration.
Best for: application-ui, content-docs, ai-chat  ·  Poor fit for: marketing landing pages, personal websites
Palette roles: white `#FFFFFF`, layer `#F4F4F4`, text-primary `#161616`, text-secondary `#525252`, interactive `#0f62fe` (Blue 60), support-error `#da1e28`, support-success `#198038`, dark base `#161616` with `#262626` layers and `#4589ff` interactive
Typography: IBM Plex Sans (OFL, open), IBM Plex Mono for code, IBM Plex Serif optional. Type scale in fixed steps; prefer tabular figures for data. Open fallback: Inter, Source Sans 3.
Shape & space: 2px radius on most controls (square, technical). 16px spacing base unit; two-column layout grid; dense table rows.
Motion: 110ms `cubic-bezier(0.2, 0, 0.38, 0.9)` micro-transitions; motion is functional only
Signature moves: thin hairline separators, a persistent left icon nav rail with flyouts, inline status tags, high-contrast table headers, the `0f62fe` interactive blue on grayscale
Do not copy: the IBM mark, IBM product names in UI, IBM Plex trademark beyond the open font license
Slop overlap: none
