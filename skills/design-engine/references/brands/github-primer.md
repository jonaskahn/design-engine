# GitHub Primer
Source: https://primer.style/ (foundations, color, components; github/primer GitHub)  ·  Tokens verified: 2026-10 (model knowledge; re-verify at lock-in) against https://primer.style/foundations/color
Status: active. Functional color system (fg/muted/emphasis/success/attention/danger/done/severe/sponsors), multiple canvas modes.
Character: Technical and utilitarian, optimized for code, diffs, and long lists of records. The design stays out of the way of content.
Best for: application-ui, content-docs, ai-chat  ·  Poor fit for: emotive brand marketing, hospitality
Palette roles: canvas-default `#ffffff`, canvas-subtle `#f6f8fa`, fg-default `#1F2328`, fg-muted `#656D76`, accent-emphasis `#0969da`, success-emphasis `#1a7f37`, danger-emphasis `#cf222e`, done `#8250df`, dark canvas `#0d1117` with `#30363d` borders
Typography: Mona Sans / Hubot Sans (variable, open from GitHub). Monospace: JetBrains Mono or SF Mono for code. Open fallback: Inter, Source Sans 3.
Shape & space: 3px–6px radius; 8px spacing base; low contrast borders for structure rather than shadows
Motion: minimal, ~100ms opacity/color transitions; respect reduced motion
Signature moves: border-driven surfaces, monospace code blocks, neutral gray pill labels, tables with subtle zebra, green/red diff semantics
Do not copy: the GitHub mark, Octocat, the word "GitHub" in your UI
Slop overlap: dark-only (GitHub Dark is deliberate), pill-shaped labels
