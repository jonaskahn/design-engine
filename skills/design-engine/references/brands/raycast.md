# Raycast
Source: https://www.raycast.com/ (observable brand/product design)
Character: Fast, confident developer tooling. Dense, dark, keyboard-driven, with sharp typographic polish.
Poor fit for: public/consumer retail, government
Palette roles: background `#1C1C1C`-family, elevated panel `#242424`, text `#FFFFFF`, muted `#98989E`, accent red/orange `#FF6363`-family, focus ring blue
Typography: Inter (custom cut for Raycast), tight display. Open fallback: Inter, Geist Sans. Compact command-list type with shortcut hints in monospace.
Shape & space: 6–10px radius on panels; compact 4px spacing; centered floating command window
Motion: very fast transitions; search-as-you-type responsiveness is the primary feedback
Signature moves: centered command palette window, keyboard shortcut chips in every row, dark elevated panels, red accent, blurred background behind the window
Slop overlap: dark-only, Inter, glass blur (deliberate here)
