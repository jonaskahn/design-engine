# Notion
Source: https://www.notion.com/ (observable product/marketing design; no full public token spec — record "observed from https://www.notion.com/")
Character: Quiet, document-first, and warm. Text is the interface; chrome recedes.
Poor fit for: dense data dashboards, gaming
Palette roles: canvas `#FFFFFF`, sidebar `#F7F7F5`, text `#37352F`, muted `#787774`, border `#E9E9E7`, accent blue `#2383E2`; dark `#191919`
Typography: Inter (product), serif options in docs (Lyon/Tiempos style). Open fallback: Inter, Source Serif 4 for body. Friendly, high-legibility body type.
Shape & space: 3px small radius, 8px cards; 4px spacing base; generous whitespace for reading
Motion: very restrained; hover reveals and smooth page transitions
Signature moves: gray sidebar on white content canvas, emoji page icons, toggle and callout blocks, hairline dividers, text-first layout
Licensing: Trademarked block icons.
Slop overlap: Inter, emoji in UI (deliberate here)
