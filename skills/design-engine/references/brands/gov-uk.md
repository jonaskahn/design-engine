# GOV.UK Design System
Source: https://design-system.service.gov.uk/ (styles: colour, typography, layout, components)
Character: Clear, plain, and inclusive. Optimized for task completion by the widest possible public audience, not for brand expression.
Poor fit for: luxury/consumer brand sites
Palette roles: canvas `#FFFFFF`, secondary canvas `#F3F2F1`, text `#0B0C0C`, muted text `#505A5F`, focus yellow `#FFDD00`, link blue `#1D70B8`, success green `#00703C`, error red `#D4351C`, dark blue `#0B0C0C` banner
Typography: GDS Transport (proprietary, restricted to gov.uk domains — never ship it elsewhere). Open fallback: Helvetica Neue → Arial, Roboto. Large, plain body type; clear heading hierarchy.
Shape & space: square/slight radius, very generous touch targets (min 48px), 4px spacing base with large section gaps
Motion: virtually none by default; text updates use accessible focus handling
Signature moves: blue underlined links, thick yellow focus indicator, black/grey banner headers, numbered "Step 1 of N" task progress, plain form fields with "for example" hints
Licensing: GDS Transport font is restricted; Crown copyright applies.
Slop overlap: none (explicitly plain; strong reference for anti-slop restraint)
