# Personal Website Branch

Use for portfolios, résumés, personal brands, creator sites, and individual professional websites.

## Required context

Collect only what is missing:

- the person's name or a placeholder;
- role, identity, or positioning statement;
- intended audience and desired impression;
- work, projects, writing, résumé, biography, or other required content;
- primary action, such as viewing work, contacting, hiring, following, or downloading a résumé;
- available portrait, project imagery, résumé, social links, and brand assets.

Do not invent biography, employers, clients, project outcomes, contact details, or social accounts.

## Branch decisions

### Hero format

- Full-screen photography or visual background
- Large headline with a supporting image
- Headline-only minimal composition
- Split text-and-visual layout
- Interface- or project-preview-led composition
- Motion- or video-led introduction

### Hero emphasis

- Name
- Role or identity
- Value statement
- Name and role equally

### Navigation

- Very simple top navigation
- Transparent floating navigation
- Solid fixed navigation
- Side navigation
- Minimal or deferred navigation in the first screen

Ask about navigation only when the content volume makes the choice consequential.

### Work presentation

- Large visual showcases
- Card grid
- Vertical list
- Timeline
- Alternating editorial layout

Clarify the project detail path when relevant: inline summary, dedicated case-study page, modal, or external link.

### Card usage

- Avoid cards where possible
- Use cards in supporting content
- Use cards only for projects
- Use cards throughout

### Contact presentation

- Short invitation with one button
- Contact cards
- Social links with email
- Full contact section with supporting copy

Protect private contact details when the prompt will be sent to an external tool; retain labeled placeholders unless the user approves otherwise.

## Output emphasis

The final prompt must define the narrative order, project presentation, credibility signals, contact path, and how the personal identity remains recognizable across device sizes.
