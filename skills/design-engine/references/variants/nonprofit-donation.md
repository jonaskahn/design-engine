# Nonprofit and Donation Variant

Hosted by [marketing-website.md](../marketing-website.md). Read the marketing core for hero, navigation, feature narrative, and CTA questions; use this file only for what a donation or fundraising page adds.

## Required context

- organization mission and the cause being supported;
- real impact figures, beneficiary information, or financial ratios, if approved for use;
- donation processor or payment mechanism available;
- fund designations, if multiple causes or campaigns exist.

Never invent impact figures, beneficiary stories, financial ratios, charity ratings, or tax-deductibility claims.

## Branch decisions

### Impact storytelling model

- Single central story or cause
- Multiple program areas presented side by side
- Data-led (verified metrics and outcomes)

### Donation form placement

- Embedded directly in the hero
- Sticky donation panel throughout the page
- Dedicated donation section lower on the page
- Handoff to an external donation processor

### Amount presentation

- Preset amount buttons with a custom-amount option
- Custom amount only
- Suggested impact framing per amount (only with real, approved figures)

### Giving frequency

- One-time only
- Recurring emphasized as the default
- Equal one-time and recurring options

### Progress display

- Goal progress bar or meter, only with real, current numbers
- No progress display

### Fund designation

- Single fund, no choice needed
- Dropdown or selector for multiple funds or campaigns

## Required states

- Goal reached
- Campaign ended
- Donation processing error

## Output emphasis

The prompt must define donation flow placement, amount and frequency presentation, and transparency treatment without fabricating any figures or claims.
